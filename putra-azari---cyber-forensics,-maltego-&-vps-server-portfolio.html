Analisis Forensik Digital

Rekonstruksi insiden siber melalui analisis memori terenkripsi, artefak disk, log audit, dan jaringan terisolasi.

[FORENSIC_TOOL_01]

Memory Forensics

Analisis RAM dump menggunakan Volatility Framework untuk mengekstrak hidden process, injected code, DLLs, & network socket.

> volatility -f mem.raw imageinfo
[FORENSIC_TOOL_02]

Disk Artifacts Analysis

Eksplorasi MFT, Registry hives, Event logs, Prefetch, MFT journaling, dan recovery berkas yang terhapus.

> autopsy / SleuthKit Engine
[FORENSIC_TOOL_03]

Network PCAP Triage

Analisis lalu lintas paket data Wireshark/TShark, deteksi command & control (C2) beacon, serta ekstraksi payload.

> tshark -r capture.pcap -q -z
[FORENSIC_TOOL_04]

Chain of Custody & Legal

Penerapan hashing cryptographic (SHA256/MD5), dokumentasi barang bukti digital, serta penyusunan laporan audit resmi.

> sha256sum evidence_disk.dd
